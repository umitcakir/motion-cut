# Security Policy

## Supported Versions

Motion Cut is currently an alpha project. Security fixes are applied to the latest development version.

## Reporting A Vulnerability

Do not open a public issue for a suspected security vulnerability. Report it privately to the repository owner through GitHub with:

- a clear description of the issue;
- steps to reproduce it;
- affected platform and Motion Cut version;
- potential impact, if known.

Please allow time for investigation before sharing details publicly. Do not include passwords, API keys, camera recordings, or other sensitive data in the report.
